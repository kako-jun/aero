# aero

**周囲の音の異変を小さく知らせる、聴覚障害者・難聴者向け desktop アプリ**

`aero` は、読書中・執筆中・別アプリ作業中などに、**周囲の音が急に大きくなったことへ気づきやすくする** desktop-first のアクセシビリティアプリです。

字幕アプリではありません。音声認識で Google と競うものでもありません。役割はもっと手前です。

- まわりで何か変化が起きた
- それを小さなインジケータで知る
- 必要ならそのあと相手を見る、別手段につなぐ

## MVP

- **desktop 常駐オーバーレイ** — 右下付近の小さな always-on-top インジケータ
- **平常との差分検知** — 絶対音量ではなく、直近の平常値からの上振れを見る
- **緑 → 黄 → 赤** — 強い変化でトゲトゲ吹き出し形状になる
- **簡易分類（将来）** — 人っぽい / 物音っぽい を小さなドット絵で示す
- **クラウド前提にしない** — 音は保存・送信しない方針

## 対応方針

- **第一対応 OS:** Windows
- **技術スタック:** Tauri
- **将来:** Android は必要なら別実装で対応

## 想定シーン

- 視界外から名前を呼ばれる
- 周囲が急にざわつく
- 近くで大きな物音がする
- PC 作業に集中していて気づきにくい

## 開発

```bash
# Frontend
cd frontend
npm install
npm run dev

# Tauri desktop shell
npm run tauri:dev
```
